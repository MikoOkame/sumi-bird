## sumi-bird
リポジトリ名を改名。
テクスチャなしの鳥モデルを、墨絵の陰影で眺めるビューア。Three.js。アニメーションは28クリップ。

公開ページは [墨鳥](https://mikookame.github.io/grok-sandbox/) 。

`npm install` のあと `npm run dev`。ブラウザで http://127.0.0.1:8080/ 。

モデルは `public/bird.glb` 。Pages もそこを読む。
